# 贡献

<!-- section:contract -->
## 合约

贡献必须保持仅本地和无真实交易边界。变更这些合约时，为校验、注册标识、工作区隔离、幂等和失败状态补充测试。GUI 指引保留在原手册，不要在软件包 API 文档中重写。

新的公共因子或策略须有可独立实现的版本、校验器、夹具、来源说明和信息时点评审。私有因子代码或凭证不得进入公共制品。

<!-- section:evidence -->
## 证据

审阅前运行受影响 CLI 与相关测试，核验公共发行边界。新增实现须经审阅，不得放松来源、凭证或私有代码检查。
