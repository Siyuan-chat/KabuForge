1. 起動と画面

KabuForge のランチャーから起動します。右上で日本語・简体中文・Englishを選択できます。言語はワークスペースに保存され、切り替えても入力は失われません。左のナビゲーションからホーム、マイ戦略、データセンター、結果、ペーパートレード、証券会社接続、実行履歴へ移動します。狭い画面では戦略一覧を上に配置します。

ローカルの経路は、合成デモ、取得データの価格リサーチ、準備済みの実データ研究パッケージの三つです。通常フォームは読み込んだ run を編集しません。詳細設定は宣言的設定の読込、事前確認、審査に使います。

KabuForgeはオレンジの金床ロゴとグラファイトの背景を使用し、ウィンドウとタスクバーにも同じブランドのアイコンを使います。オレンジは主要操作の強調で、利益や損失を表しません。数値・符号・状態表示を確認してください。

2. キー不要のオフラインデモ → · 目次

2. キー不要のオフラインデモ

ホームのオフラインデモをクリックします。架空のデータ・戦略・模擬口座を現在のワークスペースに作成し、既存の運用台帳には触れません。完了後、マイ戦略でクオリティとトレンドの合成デモを選び、名前、銘柄数、頻度、比率、資金、手数料を入力します。

戦略を確認して作成し、バックテスト開始を押します。検証後にシミュレーションが始まり、失敗時には停止します。曲線は計算結果のみを表示します。デモ期間は2024年5月で、銘柄数は架空のユニバースに制限されます。架空の収益は戦略の有効性を証明しません。

合成デモは3つの観察日だけを提供します。週次・月次は提供カレンダー内の最後の観察日を使い、完全な取引所カレンダーではありません。ソフトウェアの動作確認専用です。

3. J-Quants APIキー

データセンターで自分のAPIキーを入力します。表示・非表示を切り替えて確認し、接続テストを実行します。テストは読取専用のデータ取得で、発注は行いません。無効なキー、権限、レート制限、ネットワークの問題が表示されます。キーを戦略説明やログ、スクリーンショットに含めないでください。

既定ではセッション中のみ保持します。安全な保存を選んだ場合だけWindows資格情報マネージャーに保存します。通常の設定JSONには書きません。保存したキーは削除できます。接続成功は全期間の取得権限を保証せず、実際のレスポンスに従います。テストと取得はAPI利用枠を消費する場合があります。

4. ダウンロードと再開 → · 目次

4. ダウンロードと再開

銘柄コード、開始日、終了日を指定して取得します。最初は少数銘柄・短期間を推奨します。保存先は現在のワークスペース内のjquants_downloadsです。進捗表示と中止ボタンがあります。同じ条件の再試行は検証済みページから再開し、未完了ファイルを完全なデータとして扱いません。

期間を広げると別のリクエスト記録になります。完了した清単は価格モメンタムの入力に使用できます。再起動後は以前のmanifest.jsonを選択できます。取得した履歴は現在の版であり、過去時点での可視性を保証しません。取得時刻を過去のavailable_atとして使いません。

7. 実データの価格リサーチ → · 目次

5. フォームで戦略を作成

識別しやすい名前を付けます。クオリティとトレンドは合成データ、価格モメンタムは取得した日足を使います。保有銘柄数は目標の上限です。均等配分では選択銘柄の目標比率を等しくします。頻度は毎日・毎週・毎月です。片道手数料は百分率で、0.10は0.10%を意味します。

クオリティ比率は合成デモ専用で、残りがトレンドです。価格モメンタムでは観察期間前の終値を用いて順位を計算します。初期資金は円単位です。作成した設定を確認してから実行してください。Ctrl+O または --run で実データ研究パッケージを読み込んだ場合は、「戦略を作成」を押して上書きしないでください。

再起動後はマイ戦略の上部リストから保存済み戦略を選び、開くボタンを押します。テンプレートと資金設定も復元します。詳細JSONを変更した場合は保存と再検証が必要で、元のフォームと一致していると見なしません。

6. 文章入力の補助 → · 目次

6. 文章入力の補助

ローカル解析は限られた三言語表現に対応します。例は「毎月5銘柄を均等配分」、「每月选5只股票，等权」、「Select 5 stocks monthly, equal weight」です。フォーム反映で変更されるのは銘柄数、頻度、均等配分です。

空売り、レバレッジ、損切りなど未対応の条件や矛盾する数・頻度は推測せず拒否します。結果を確認し、その他の項目はフォームで設定します。外部AIは使わず文章を送信しません。解析のみでは戦略の作成・実行は始まりません。

7. 実データの価格リサーチ

取得完了後、価格モメンタムを選び、観察期間、銘柄数、頻度、資金、手数料を設定します。有効価格と全銘柄の共通カレンダーが必要です。始値・終値の欠損、売買停止、データ不足を補間で隠さず拒否します。

前営業日以前の終値で順位を決め、翌営業日の始値で調整を模擬し、終値で評価します。最初の観察期間は準備期間です。連続数量・均等配分・現金口座の簡易研究であり、単元株、スリッページ、板、市場影響は再現しません。厳密なPIT認証ではありません。株式分割の調整係数が変化する期間は単位混在を避けるため拒否します。

数量と資金配分は前日の終値で決め、翌日の始値で再計算しません。実際の始値で現金が不足すれば買注文全体をスキップします。週次・月次は準備期間後の最初の利用可能日です。指定コードは履歴全市場のユニバースではなく、選択バイアスがあり得ます。

8. ローカル実データ研究パッケージ → · 目次

8. ローカル実データ研究パッケージ

ローカル準備処理が作る最小パッケージには backtest.json、snapshot.json、timeline.json、account.json と同じフォルダーの Parquet データがあります。--run で backtest.json を指定して起動するか、Ctrl+O で選択します。読込後は通常フォームの「戦略を作成」を使わず、run を上書きしません。

Ctrl+Shift+D でデータセンターの詳細診断を開くと、同じフォルダーの timeline.json が自動で読み込まれます。Ctrl+Return で事前確認、Alt+4 で結果ページへ移動し、Ctrl+Shift+Return でバックテストを実行します。月次受入れは同じ20銘柄で 2025-04-01 から 2025-04-30 を対象とし、判断21回、NAV点21個、模擬約定11件、期末NAVは 0.9873801989 でした。実行と評価は4月2日から5月1日までで、5月1日は4月30日の判断後の次取引日における実行と評価を完了するためです。前終値は計画用の参照、始値は別の約定価格です。RESEARCH-ONLY であり、過去 API 可視性、履歴版、全戦略等価性は証明しません。

最初の事前確認では、詳細診断の判断時刻を 2025-04-01T23:59:00+09:00、実行時刻を 2025-04-02T09:00:00+09:00 に設定します。この2項目は事前確認と単発操作に使用し、履歴バックテストの各期は timeline.json を読みます。価格と銘柄集合は既存日付の引け後という研究上の扱い、財務は開示時刻で選別し、追加の D-1 は設けません。終値が欠ける場合は評価だけにその時点で既知の直近有効終値を用い、元の因子入力は補完しません。

9. 結果の読み方と比較 → · 目次

9. 結果の読み方と比較

結果ページには純資産、ドローダウン、取引と要約を表示します。純資産は初期資金で正規化し、ドローダウンは過去のピークからの下落率です。ベンチマーク未指定時に架空の線を生成しません。価格研究と合成約定のモデルは異なるため、説明も確認してください。

表はフィルター、ソート、コピー、CSV出力に対応します。比較では入力と設定の識別情報を確認します。曲線だけで特定パラメータの効果を断定しないでください。入力スナップショットと費用を保存し、失敗・中止の処理を完了結果として扱わないでください。

10. ペーパートレード → · 目次

10. ペーパートレード

合成デモ作成後、上部の実行モードで独立Paper口座を選べます。モード変更だけでは取引しません。再検証後に計画を生成し、目標と費用を確認してから独立シミュレーションを実行します。台帳パスが入力され、口座・注文・イベント・約定を読取専用で確認できます。

価格リサーチ結果を認証済みPaper入力として直接使用できません。詳細フローには明示的なスナップショット、時刻、価格が必要です。UNKNOWNや照合要求があれば新規実行を停止します。照会・確認を行い、再送しないでください。完全自動復旧と実口座は無効です。

11. 保存と記録 → · 目次

11. 保存と記録

ウィザードの戦略はワークスペースの独立フォルダーに保存され、同名でも上書きしません。詳細編集はコピー保存です。実行履歴には要求、PID、出力先、ログ、終了状態、設定スナップショットがあります。中止対象はこのアプリが開始した処理だけです。

任意で --record-dir に新しい記録フォルダーを指定して起動できます。Ctrl+Shift+R でこのウィンドウの録画を開始・停止し、Ctrl+Shift+P で単フレームを保存します。PNG は実際の Qt クライアント領域だけで、デスクトップ、マウス、ファイル選択画面を含みません。GIF は連続動画ではなく手順の要約です。Alt+7 で実行履歴を開き、撮影前にキーと個人パスを隠してください。

12. トラブルシューティング → · 目次

12. トラブルシューティング

接続エラー：キー、ネットワーク、契約範囲を確認します。レート制限時は待って再試行します。中断：同じ条件で再開し、未完了清単を研究に使いません。実行ボタンが無効：戦略作成、検証エラーの解決、他処理の完了を確認してください。

画面が狭い：ウィンドウを広げ詳細設定を閉じます。表自体は横スクロール可能です。旧JSON：詳細診断を読み、明示的に変換します。不明項目は自動削除しません。取引がない：準備期間、銘柄数、リスク条件、日程を確認します。解決しなければ操作手順と記録を報告し、キーは添付しないでください。

13. マニュアル検索とショートカット → · 目次

13. マニュアル検索とショートカット

側栏の操作マニュアルまたはF1でオフライン手冊を開きます。目次を押すと章に移動します。検索はタイトルと本文を対象とし、結果から章へジャンプできます。前・次ボタンは本文中の一致箇所を検索します。章末リンクは次章へ移動し、言語を変えても現在の章を維持します。

Alt+1〜7でページ切替、Ctrl+Oでローカル run JSON を読込、Ctrl+Shift+Oで保存済みバックテスト報告を開き、Ctrl+Shift+Lで画面言語を循環、Ctrl+Returnで事前確認、Ctrl+Shift+Dでデータ詳細診断を開き、Ctrl+Shift+Returnでバックテストを実行します。HTML は相対パス framework_v2/docs にあり、オフラインで読めます。
