## 契约

本矩阵区分公开候选版的源码实现、运行证据和安装验收。九项迁移研究实现的源码检出 GUI/worker 路径已实际核验，包括五门课程、19 图报告、缓存和 MCP 流程；这不等于干净 wheel 安装或用户环境的可选 runtime 验收。“可发现”仅表示能够列出，不代表计算已成功。

所有示例结果均为 RESEARCH-ONLY，且 `pit_guarantee=false`。输入必须由用户显式提供 CSV、Parquet 或已完成的 manifest；不会随包分发原始 J-Quants 缓存、完整报告、模型文件、凭证或 Paper 账本。已验收参考流程见[五个 GUI 研究课程](GUI_RESEARCH_COURSES.md)，截图来源与范围见[公开证据摘要](../demos/research-20261006/EVIDENCE_SUMMARY.md)。

## 如何理解能力状态

源码检出环境中的 GUI/worker 路径已实际运行验收，但与干净 wheel/安装验收分开。四个可选 runtime 组共 31 项源码 workflow tests 通过且无 skip；这是本地核验，不是 GitHub Actions 运行结果。发现 provider 或列出引擎不代表 runtime 已成功计算。只读诊断需显式调用，且与零网络离线预览不同；真实终端仍未验证。研究结果不因此升级为严格 PIT、可投资、PAPER-READY 或实盘证据。

[路线图](ROADMAP.md)记录剩余的干净 wheel/安装验收及长期研究要求。主要研究缺口包括可靠的历史可得时间、交易日历、公司行动、分红、容量与真实执行成本，以及新的前向观察。公开版本的 Regime 默认关闭，不包含私有状态机桥接。
