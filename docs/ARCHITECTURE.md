# KabuForge 发布架构

KabuForge 是本地优先的日股因子研究与历史模拟软件。发布版的目的，是让使用者以自己取得并保管的数据，在本机进行配置校验、因子计算、订单规划和合成撮合复现。它不是荐股服务、交易指令服务或真实下单系统。

## 组件与边界

`framework_v2/` 是新版核心。其配置层读取带版本的策略、因子、运行和数据快照文件；`FactorContext` 以带时区的 `available_at` 限制因子可见数据；策略层形成目标组合；规划层在资金、交易单位、报价和风险限制内产生订单意图；`Store` 将意图、事件、成交与估值记入本地 SQLite；`FakeBroker` 只执行确定性的本地模拟撮合。

发布版使用明确注册的 `public.*` 因子实现。旧工作区的私有质量、价值、残差动量及其他私有因子不属于发布包，也不会因名称相同而被自动替换或载入。公开的 `momentum_12_1` 是独立实现，不能被表述为私有残差动量的等价物。

工作台由 `framework_v2/workbench_qt.py` 和 PySide6 组成，负责配置、预检、历史模拟、独立纸上模拟、只读账本、券商能力和运行记录页面。数据中心可使用用户自行提供的 J-Quants v2 凭据下载日线至所选工作区；密钥不得写入配置、示例、日志或仓库。下载数据的取得时间不能反推历史可见时间。

品牌素材位于 `brand/kabuforge/v1/`。启动界面、图标与三语手册均引用该目录；发布时须保留其运行所需 SVG、PNG 与 `tokens.css`。三语离线手册位于 `framework_v2/docs/manual_zh_CN.html`、`manual_ja_JP.html`、`manual_en_US.html`，其内容源为 `framework_v2/manual_content.py`。

## 研究时间边界

严格输入要求每条可用数据具备明确、带时区的 `available_at`。未知时间不能以日期补足。历史股票池、行情、财务事件和执行报价均是独立输入；决策价格不能在执行时用后见报价重选。示例数据和合成演示只验证软件行为，不能证明数据的 PIT 完整性、因子有效性、历史业绩或未来收益。

## 券商与 Excel 边界

发布版不提供真实账户接入、自动恢复或真实下单。协议 mock、模拟 broker 与本机券商/Excel COM 不是同一验证等级。任何提交结果为 `UNKNOWN` 的情形都须经独立对账处理；不得重发推断为未送达的订单。软件发布不构成券商集成已验收的声明。
