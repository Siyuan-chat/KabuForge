1. 首次启动与界面

从 KabuForge 启动入口打开工作台。右上角选择简体中文、日本語或 English；语言会保存在当前工作区，切换不清除表单。左侧导航进入首页、我的策略、数据中心、回测结果、纸上交易、券商连接与运行记录。窄窗口下策略目录移到编辑区上方。

有三条本地路径：合成演示、下载数据的价格研究、以及已准备好的本地真实研究包。普通向导表单不编辑已加载的 run；高级区用于打开、预检和审查声明式配置。

KabuForge 使用橙色锻台 Logo 和石墨背景，窗口与任务栏采用同源应用图标。橙色强调主要操作，不代表盈利或亏损；请以数值、正负号和文字状态为准。

2. 无需密钥的离线演示 → · 目录

2. 无需密钥的离线演示

在首页点击“体验离线演示”。程序在当前工作区创建独立的虚构数据、策略和模拟账户，不读取旧生产账本。等待任务完成后，进入“我的策略”，选择“质量与趋势（合成演示）”，输入名称、持仓数量、调仓频率、质量占比、初始资金和费用。

点击“检查并创建策略”后检查摘要，再点击“开始回测”。程序先预检，再启动历史模拟；失败会停止，不会绕过校验。曲线只来自完成的计算。演示日期固定在 2024 年 5 月；持仓上限取决于虚构股票池。虚构收益不能作为策略有效性的证据。

合成演示提供稀疏的三个观察日。周期调仓取所提供日历中每周或每月最后一个观察日，并非完整交易所日历；因此仅用于验证软件流程。

3. 配置 J-Quants API key

进入数据中心，在 J-Quants 连接区输入你自己的 API key。使用显示/隐藏按钮检查输入，点击测试连接。连接测试是只读数据请求，不会下单。无效密钥、权限不足、限流和网络错误会显示可处理的提示。不要把密钥粘贴到策略描述、截图或日志。

默认仅在当前会话使用密钥。只有勾选安全保存后才存入 Windows 凭据管理器；这不是普通配置文件。可删除保存的凭据。连接成功不保证全部历史数据都在你的订阅权限内，最终以下载响应为准。测试与下载可能使用订阅的 API 请求额度。

4. 下载、更新与中断恢复 → · 目录

4. 下载、更新与中断恢复

在数据中心填写股票代码列表、开始日期和结束日期，再开始下载。建议先用少量股票和短日期区间验证。数据仅写入当前工作区的 jquants_downloads 目录。下载页显示进度，可取消；重试相同请求会使用已经校验的分页检查点，不把部分文件当完整数据。

扩展日期范围会形成另一份请求记录，不会改写原有研究证据。完成后清单会接入“我的策略”的价格动量模板。重新打开软件时可通过文件选择器选择之前的 manifest.json。数据来自当前取得的历史版本，不自动代表严格的历史可见版本；下载时间不是历史 available_at。

5. 用表单创建策略

给策略取一个易识别的名称。模板决定数据和计算方式：质量与趋势使用合成演示；价格动量使用已下载的日线数据。持仓数量为目标上限，等权指选中股票的目标权重相同。调仓支持每日、每周、每月。费用以单边百分比输入，例如 0.10 表示 0.10%，并非 10%。

质量占比仅用于合成演示，剩余为趋势因子；两者不是价格动量模板的参数。价格动量使用观察期前的收盘价计算排名。初始资金以日元计。先创建并审阅策略，再开始回测；已通过 Ctrl+O 或 --run 加载本地研究包时，不要点“检查并创建策略”覆盖它。

重新启动后，可在我的策略页上方的下拉框选择已保存策略，再点击打开已保存策略。模板与资金参数会一起恢复。修改已加载的高级 JSON 后，须保存并重新检查，不能当作向导表单仍与旧参数一致。

6. 自然语言辅助填写 → · 目录

6. 自然语言辅助填写

当前支持本地、受约束的三语表达，例如“每月选5只股票，等权”、“毎月5銘柄を均等配分”或“Select 5 stocks monthly, equal weight”。点击解析到表单，只会填写数量、频率和等权方式。

含做空、杠杆、止损等未支持条件，或相互矛盾的数量/频率时，解析会提示不能完整理解，不应用猜测。解析结果仍需检查；其他参数用表单设置。此功能不访问外部 AI，不发送你的策略描述，也不自动创建或运行策略。

9. 阅读和比较回测结果 → · 目录

7. 下载数据的价格研究

完成下载后，选择价格动量模板，设置观察期、持仓数、调仓频率、初始资金和费用。数据必须包含有效价格，且每个参与股票覆盖同一研究日历；缺失开盘/收盘、停牌或样本不足时会拒绝研究，而非编造价格。

该研究用前一交易日及更早的收盘信息排序，在下一交易日开盘价模拟调整，以收盘价估值。观察期需要预热，前若干天不产生交易。按完整股票池共同日期工作；当前采用连续份额、等权、现金账户的简化研究，不模拟整手、滑点、盘口或市场冲击，也不构成严格 PIT 认证。遇到拆股调整因子变化时拒绝运行，避免混用单位。

数量和目标资金按前日收盘价格确定，不读取次日开盘价来重新定量；实际开盘现金不足则整笔跳过该买单。每周/每月取预热完成后的第一个可用交易日。下载代码构成用户指定的研究股票池，不是历史全市场股票池，可能存在选择偏差。

8. 运行本地真实研究包 → · 目录

8. 运行本地真实研究包

本地准备流程生成的最小研究包包含 backtest.json、snapshot.json、timeline.json、account.json 及同目录的 Parquet 数据。以 --run 指向 backtest.json 启动，或按 Ctrl+O 选择它。导入后不要使用普通向导的“检查并创建策略”；该表单不是已加载 run 的编辑器。

按 Ctrl+Shift+D 展开数据中心的高级诊断；同目录的 timeline.json 会自动加载。按 Ctrl+Return 预检，再按 Alt+4 到回测结果页，Ctrl+Shift+Return 运行模拟。整月验收覆盖 2025-04-01 至 2025-04-30 的同一 20 只股票：21 次决策、21 个 NAV 点、11 笔模拟成交，期末 NAV 为 0.9873801989。执行和估值从 4 月 2 日延续至 5 月 1 日，后者完成 4 月 30 日决策后的下一交易日执行与估值。前收盘只作计划参考价，执行开盘报价另行结算。结果为 RESEARCH-ONLY：未证明历史 API 可见时间、历史版本或全策略等价。

首次预检前，把高级诊断中的“决策时间（含时区）”设为 2025-04-01T23:59:00+09:00，“执行时间（含时区）”设为 2025-04-02T09:00:00+09:00。这两个表单值供预检和单次操作使用；历史回测逐期读取 timeline.json。价格和股票池按已有日期的收盘后研究口径使用，财务按披露时刻筛选，不另加 D-1。缺失收盘仅在估值时使用当时已知的最近有效收盘；原始因子输入不填补。

9. 阅读和比较回测结果 → · 目录

9. 阅读和比较回测结果

回测结果页显示净值、回撤、交易记录和摘要。净值从初始资金归一化；回撤表示相对于此前净值峰值的跌幅。未提供基准时不会生成虚构基准。价格研究的模型说明与合成执行模型不同，应连同结果一起阅读。

表格支持筛选、排序、复制和 CSV 导出。运行比较检查输入和配置身份，不能仅凭两条曲线就认定差异来自某个参数。所有结果应保留输入快照和费用设置。失败或取消的任务不能作为完成结果使用。

10. 纸上交易与账户边界 → · 目录

10. 纸上交易与账户边界

合成演示创建后，可在顶部执行模式选择独立 Paper 模拟账户。模式切换不会自动交易。重新预检后先生成计划，审阅目标和费用，再执行独立模拟。运行结果中的账本路径会填入查询框，可只读查看账户、订单、事件和成交。

当前价格研究结果不能直接充当已认证的 Paper 输入。高级 Paper 流程需要显式快照、时间与执行报价。UNKNOWN 或需要对账的状态会阻止新执行，应查询和审查，不要盲目重发。完整自动恢复仍未启用；真实券商账户也未启用。

11. 保存、运行记录和截图 → · 目录

11. 保存、运行记录和截图

向导创建的策略保存在当前工作区，使用独立目录，重复名称不覆盖旧策略。高级编辑可保存副本，原配置保留。运行记录保存请求、进程身份、输出目录、日志、退出状态和配置快照。应用只取消自己启动的任务，不处理其他程序。

可选用 --record-dir 指定一个新的记录目录启动。Ctrl+Shift+R 开始或停止本窗口录制，Ctrl+Shift+P 保存单帧；PNG 仅含真实 Qt 客户区，不含桌面、鼠标或文件对话框。GIF 是步骤摘要，不是连续视频。按 Alt+7 查看运行记录，截图前隐藏密钥和个人路径。

12. 常见问题 → · 目录

12. 常见问题

连接失败：检查 key 是否有效、网络能否访问 J-Quants、套餐是否包含请求数据；限流时等待再试。下载中断：保持相同代码和日期重试，不能把未完成清单用于回测。回测按钮不可用：先完成策略创建，处理预检错误，并等待正在运行的任务。

界面过窄：放大窗口，折叠高级设置；表格允许自身横向滚动。旧 JSON 不兼容：查看高级诊断并显式转换，程序不自动删除未知字段。结果无交易：检查预热期、样本数量、风险限制和调仓日期。错误仍未解决时保存运行记录，报告操作步骤，不提供密钥。

13. 手册搜索与快捷键 → · 目录

13. 手册搜索与快捷键

点击侧栏“操作手册”或按 F1 打开内置离线手册。左侧目录点击即可跳到章节；搜索框同时检索标题和正文，结果可直接跳到对应章节。右侧上一处/下一处在当前手册中查找关键词。章节末尾的链接可跳到下一章；语言切换后保留当前章节。

Alt+1 到 Alt+7 切换工作页；Ctrl+O 导入本地 run JSON；Ctrl+Shift+O 打开已保存的回测报告；Ctrl+Shift+L 循环界面语言；Ctrl+Return 预检；Ctrl+Shift+D 展开数据高级诊断；Ctrl+Shift+Return 运行回测模拟；Ctrl+S 保存配置副本。手册 HTML 位于相对路径 framework_v2/docs，可离线阅读。
