# 路线图

<!-- section:contract -->
## 合约

公开源码候选 `0.2.0rc1` 尚未发布。研究流程、迁移实现、五门课程、19 图报告及缓存/MCP 等 GUI/worker 路径已在源码检出环境实际核验。任何发行版验收声明都必须绑定具体 wheel 文件名、SHA-256、版本、Python/平台、安装后的模块来源及该制品上按操作执行的检查；源码回执和截图不能代替已安装 wheel 的证据。

### 当前工程阶段

- 保持五条研究流程可从用户显式选择的本地文件复现：行情导入与身份、技术指标、因子评价、模型/策略/引擎比较、Historical Paper 回放。券商映射和显式只读诊断与订单提交分开。
- 每次声明发行版通过时，都应在支持的 Python 3.12 隔离环境安装已标识的 wheel，运行所选操作的 runtime 检查，并将回执与同一制品身份绑定。源码侧四个可选 runtime 组共 31 项 workflow tests 通过且无 skip；这是本地核验，并非 GitHub Actions 运行结果。metadata 或 capability registry 中出现库，不代表计算成功。
- 保留源码哈希、recipe、输入选择身份、worker 日志和失败 receipt。不把所有者的原始行情缓存、完整报告、模型文件或 Paper 账本放入安装包。
- 所有历史研究均保持 RESEARCH-ONLY、`pit_guarantee=false`。回放的是已经观测过的历史，不是新的样本外证据或前向 Paper。

### 后续研究与生态阶段（v0.3+）

- 推进严格 PIT 数据支持，需可信的历史可得时间、修订、survivorship、交易所日历、公司行动与分红处理。下载日期不能充当这些证据。
- 在提升 readiness 前，评估真实容量、流动性、费用、滑点、市场冲击和新的前向 Paper 观察。
- 只有在具备明确 capability gate、可复现证据和单独审阅时才扩展引擎及券商集成。真实终端连接尚未验证；实盘提交/撤销仍禁用。
- 除非另行迁移并审阅，私有 Regime 状态机桥接不纳入公开构建。公开版 Regime 默认关闭。

这些是范围明确的后续阶段，不代表未来 v1 会包含所有研究或执行能力。

任何 R3 交易扩展均以可信券商集成、人工审批权威、动作绑定的一次性审批、持久提交/核对账本及单独明确授权为前提；R3 schema 或本路线图本身不构成授权。

## 证据

公开版状态见[集成能力矩阵](INTEGRATIONS.md)，其中分别说明源码实现、可发现性、源码运行、源码 GUI/worker 验收、干净 wheel/安装验收及真实终端验证。已验收的参考运行覆盖 3 只日本证券和 1,464 个观测日，但数据由用户提供，不随安装包分发。限制和复现步骤见[GUI 研究课程](GUI_RESEARCH_COURSES.md)。

既有 R3 边界保持不变：R3 不在默认 MCP 目录中，即使暴露保留 stub 仍禁用。Agent 异步工作仍使用进程内 daemon 线程，并以失败关闭方式处理中断。
