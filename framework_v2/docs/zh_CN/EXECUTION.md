# 执行边界

<!-- section:contract -->
## 合约

规划器从许可目标、账户、执行报价、标的、能力、明确时间、换手预算和费用生成券商中立订单意图，并拒绝不支持的订单类型和有效期。研究价格用于现有持仓估值，执行报价用于交易规划，二者不得混用。

本地模拟使用确定性假券商。纸面与回测均为本地运行，始终报告 `external_submission: false`。工作台中的 broker 模式不可执行。

<!-- section:evidence -->
## 证据

本地账本仅将 SQLite 提交作为原子边界。若外部状态不确定，重试前必须获得券商核对证据；本包不会执行此核对或重发真实订单。
