# 安全

<!-- section:contract -->
## 合约

Agent 输入经过 schema 校验和凭证类值检查。相对路径在工作区内解析；绝对路径、穿越、逃出根目录的符号链接及受保护凭证/控制位置均被拒绝。工作区 JSON 读取限制为 64 MiB，MCP 单行限制为 1 MiB。

R2 修改需要调用方提供调用 ID 和幂等键。R3 保持禁用。人工审批必须来自可信的未来主机并且一次性消费；Agent 工具和配置值都不能创建它。

<!-- section:evidence -->
## 证据

调用回执在工作区 SQLite 中保存调用 ID、幂等键、输入/结果哈希、运行 ID、时间、工具和状态。复用幂等键返回既有持久结果或不确定性拒绝，不会静默重复修改。
