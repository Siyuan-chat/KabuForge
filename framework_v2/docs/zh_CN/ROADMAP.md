# 路线图

<!-- section:contract -->
## 合约

本轮 RC 使既有公开实现可独立安装；后续补充夹具、数据来源、依赖审阅，并扩展超越时间戳门控的研究验证与运行可复现性证据。

任何 R3 交易扩展均以可信券商集成、人工审批权威、动作绑定的一次性审批、持久提交/核对账本及单独明确授权为前提；R3 schema 或本路线图本身不构成授权。

当前 R3 不在默认 MCP 目录中，即使暴露保留 stub 仍禁用。异步任务当前使用进程内 daemon 线程，并以失败关闭方式处理中断。
