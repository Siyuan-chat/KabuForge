1. Starting and navigating

Launch KabuForge and choose English, 简体中文 or 日本語 at the top right. The workspace remembers the language; switching does not clear your input. Use the sidebar for Home, My strategies, Data center, results, paper trading, broker capabilities and run history. Narrow windows place the strategy list above the editor.

There are three local paths: synthetic demo, price research from downloaded bars, and a prepared local real-data research package. The regular wizard form does not edit a loaded run; advanced controls open, preflight and inspect declarative configuration.

KabuForge uses the orange anvil logo and graphite surfaces, with the supplied application icon for the window and taskbar. Orange highlights primary actions; it does not indicate profit or loss. Read values, signs and status text.

2. Offline demo without a key → · Contents

2. Offline demo without a key

Click Try offline demo on Home. It creates fictional data, a strategy and an isolated simulated account in this workspace, without reading production ledgers. When complete, open My strategies, choose Quality and trend (synthetic demo), and enter a name, holding count, frequency, quality allocation, capital and fees.

Review and create the strategy, then start the backtest. Validation runs first and stops the workflow on failure. Charts only show computed results. The demo covers May 2024 and its fictional universe limits the holding count. Fictional returns are not evidence of investment performance.

The synthetic demo supplies only three observation sessions. Weekly/monthly schedules choose the last supplied observation in each period, not a complete exchange calendar. This is a software workflow check only.

3. Connecting J-Quants

Enter your own API key in Data center. Toggle visibility to check it, then test the connection. The test is a read-only data request and does not place orders. Invalid keys, access restrictions, rate limits and network failures are reported. Never paste a key into strategy descriptions, screenshots or logs.

Keys stay in memory by default. Only the explicit secure-save option writes to Windows Credential Manager, never ordinary strategy JSON. Saved keys can be deleted. A successful connection does not guarantee access to every historical period; the actual API response determines availability. Tests and downloads may consume your subscription request allowance.

4. Downloading and resuming → · Contents

4. Downloading and resuming

Enter stock codes and start/end dates, then download. Begin with a small universe and short interval. Files are confined to jquants_downloads inside this workspace. Progress and cancellation are available. Retrying the same request resumes verified page checkpoints; partial files are never treated as complete data.

Extending the interval creates a separate request record rather than rewriting previous research evidence. A completed manifest can be used by the price momentum template. After restarting, select the previous manifest.json through the file picker. Downloaded history reflects the version available now, not certified historical visibility. Retrieval time is not historical available_at.

5. Creating a strategy with controls

Give the strategy a recognizable name. Quality and trend uses the synthetic demo; price momentum uses downloaded daily bars. Holding count is a target upper limit. Equal weight gives selected stocks equal target allocations. Rebalance daily, weekly or monthly. Fees are one-way percentages: 0.10 means 0.10%, not 10%.

Quality allocation applies only to the synthetic demo; the remaining allocation is trend. Price momentum ranks using earlier closes over the selected lookback. Capital is in JPY. Create and inspect the configuration before running. When a local research package has been loaded with Ctrl+O or --run, do not click Review and create strategy: that wizard is not the loaded run editor.

After restarting, choose a saved strategy from the list above the form and click Open saved strategy. Template and capital settings are restored together. Editing advanced JSON requires saving and checking again; it invalidates any assumption that the original guided form still matches the configuration.

6. Sentence-assisted configuration → · Contents

6. Sentence-assisted configuration

The local parser supports constrained expressions in three languages, such as 'Select 5 stocks monthly, equal weight', '每月选5只股票，等权' and '毎月5銘柄を均等配分'. Parse into form only updates count, frequency and equal weighting.

Unsupported requirements such as shorting, leverage or stop losses, and conflicting numbers or frequencies, are rejected rather than guessed. Inspect the result and set other parameters in the controls. No external AI is contacted and your sentence is not transmitted. Parsing alone never creates or runs a strategy.

9. Reading and comparing results → · Contents

7. Price research with downloaded bars

After download, select price momentum and set lookback, count, frequency, capital and fees. Valid prices and a common calendar across all selected stocks are required. Missing opens/closes, suspensions and insufficient history cause a refusal instead of invented prices.

Ranking uses the previous session's close and earlier observations; rebalancing is simulated at the next session's open and valued at the close. Initial sessions are warm-up. This simplified cash-account research uses continuous units and equal weights, without board lots, slippage, order books or market impact. It is not strict PIT certification. Periods with changing split-adjustment factors are rejected to avoid mixing share units.

Quantities and target capital are sized from prior closes, never resized using the next open. A buy is skipped in full if the actual opening cost exceeds cash. Weekly/monthly research uses the first available session after warm-up. User-selected codes are not a historical whole-market universe and may introduce selection bias.

8. Running a local real-data research package → · Contents

8. Running a local real-data research package

A minimum package prepared locally contains backtest.json, snapshot.json, timeline.json, account.json and Parquet data beside them. Start with --run pointing to backtest.json, or press Ctrl+O and select it. After loading, do not use the regular wizard's Review and create strategy action; it is not an editor for the loaded run.

Press Ctrl+Shift+D to expand Data center advanced diagnostics; timeline.json beside the run loads automatically. Press Ctrl+Return to preflight, Alt+4 for Results, then Ctrl+Shift+Return to run the simulation. Month acceptance covers 2025-04-01 through 2025-04-30 with the same 20 stocks: 21 decisions, 21 NAV points, 11 simulated fills and ending NAV 0.9873801989. Execution and valuation run from April 2 through May 1; May 1 completes next-session execution and valuation after the April 30 decision. The prior close is a planning reference only; the opening execution quote settles separately. This is RESEARCH-ONLY: historical API visibility, historical versions and full-strategy equivalence are not proven.

Before the first preflight, set the advanced decision timestamp to 2025-04-01T23:59:00+09:00 and execution timestamp to 2025-04-02T09:00:00+09:00. These form values serve preflight and single-step operations; historical backtests read each period from timeline.json. Prices and universe data use their existing dates under an after-close research convention; financial data is filtered by disclosure time, with no additional D-1 lag. A missing close uses the most recent valid close known at that time for valuation only; raw factor inputs are not filled.

9. Reading and comparing results → · Contents

9. Reading and comparing results

Results show NAV, drawdown, trades and a summary. NAV is normalized by initial capital; drawdown is the fall from the previous NAV peak. No benchmark is invented when absent. Read the model explanation: price research and synthetic quote matching use different assumptions.

Tables support filtering, sorting, copying and CSV export. Comparisons inspect input and configuration identities; two curves alone do not establish a parameter's effect. Retain configuration snapshots and fee settings. Failed or cancelled tasks are not completed results.

10. Paper trading boundaries → · Contents

10. Paper trading boundaries

After creating the synthetic demo, select the isolated Paper account in the top execution-mode selector. Switching modes does not execute trades. Check inputs again, create a plan, inspect targets and fees, then run the isolated simulation. The resulting ledger path is filled in for read-only account, order, event and fill queries.

A price-research result is not certified Paper input. Advanced Paper workflows require explicit snapshots, timestamps and execution quotes. UNKNOWN or reconciliation-required states block new execution. Query and investigate instead of resending. Fully automatic recovery and live accounts remain disabled.

11. Saving, recording and retaining evidence → · Contents

11. Saving, recording and retaining evidence

Wizard strategies are stored in independent workspace folders; repeated names do not overwrite earlier versions. Advanced editing saves a copy. Run history retains requests, process IDs, output paths, logs, exit states and configuration snapshots. Cancellation only affects processes started by this workbench.

Optionally launch with --record-dir pointing to a new record directory. Ctrl+Shift+R starts or stops recording this window and Ctrl+Shift+P saves one frame. PNG contains only the actual Qt client area, never the desktop, mouse pointer or a file dialog. A GIF is a step summary, not continuous video. Alt+7 opens run history; hide keys and personal paths before capture.

12. Troubleshooting → · Contents

12. Troubleshooting

Connection failed: check the key, network and subscription access; wait before retrying a rate limit. Interrupted download: retry identical codes and dates, and do not use an incomplete manifest. Disabled run button: create the strategy, resolve validation errors and wait for active jobs to finish.

Cramped screen: enlarge the window and collapse advanced settings; tables can scroll horizontally. Incompatible old JSON: inspect diagnostics and convert explicitly; unknown fields are not silently removed. No trades: inspect warm-up, sample size, risk constraints and schedule. If unresolved, retain records and report the steps without including your key.

13. Searching this guide and shortcuts → · Contents

13. Searching this guide and shortcuts

Open User guide from the sidebar or press F1. Click the contents to jump to a chapter. Search checks both headings and full text; each result opens the corresponding chapter. Previous/next match searches occurrences in the document. Links at chapter ends lead to the next chapter. Language changes retain the current chapter.

Alt+1 through Alt+7 change pages; Ctrl+O imports a local run JSON; Ctrl+Shift+O opens a saved backtest report; Ctrl+Shift+L cycles the interface language; Ctrl+Return preflights; Ctrl+Shift+D opens Data center advanced diagnostics; Ctrl+Shift+Return runs backtest simulation; Ctrl+S saves a config copy. HTML files are at the relative path framework_v2/docs and work offline.
